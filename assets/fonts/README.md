# Bundled Fonts

Ruqa bundles open-source fonts for zero-runtime-dependency typography and offline rendering on all platforms:

| Font | Purpose | License | Source / Upstream |
|---|---|---|---|
| **Aref Ruqaa Regular** | Cursive Arabic typography matching the Ruq'ah handwriting aesthetic | **OFL-1.1** (`OFL.txt`) | Khaled Hosny / Google Fonts |
| **Roboto Regular** | Clean Latin typography and numerical fallback | **Apache-2.0** (`LICENSE.apache`) | Christian Robertson / Google Fonts |

## Font Selection Rationale (ADR 0005 & ADR 0007)
Aref Ruqaa was chosen over Cairo and Amiri because it directly embodies the namesake of the project (Ruqa, from the swift, organic Ruq'ah Arabic calligraphic style). Roboto was chosen as the default Latin partner for technical terms, code snippets, and mathematical notations.
