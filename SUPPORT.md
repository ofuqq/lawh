# Support and Community

Thank you for using and exploring Ruqa!

## Where to Get Help

- **Documentation**: Check the [docs](docs/README.md) directory for architecture overviews, design proposals, and developer workflows.
- **Questions & Ideas**: For questions, design discussions, and general feedback, please visit [GitHub Discussions](https://github.com/ofuqq/ruqa/discussions).
- **Bug Reports**: If you encounter an unexpected crash or defect, search existing issues first, then open a report using our [Bug Report Template](https://github.com/ofuqq/ruqa/issues/new?template=bug_report.yml).
- **Feature Requests**: To propose enhancements or additions, submit a proposal via our [Feature Request Template](https://github.com/ofuqq/ruqa/issues/new?template=feature_request.yml).

## Project Guidelines

- **Conduct**: All interactions are subject to our [Code of Conduct](CODE_OF_CONDUCT.md).
- **Contributing**: If you want to contribute fixes or documentation, please read [CONTRIBUTING.md](CONTRIBUTING.md).
